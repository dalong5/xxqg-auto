# 旧暂停任务兼容与恢复

2026-11-07 按用户要求移除主页的“暂停任务”和“继续任务”按钮，以及按钮绑定和相关禁用/显示逻辑。账号区保留二维码、查当前积分和解绑操作；状态提示保留，不再指向已删除的按钮。

历史暂停任务与后台暂停/继续接口保留。点击原来的任务执行按钮（如“只阅读”“只答题”或“一键跑完今日”）后，若接口返回原暂停任务，页面调用继续接口，恢复同一任务并先回查官方进度，继续的是原任务清单。仅刷新网页、查积分或浏览器自检不会恢复学习任务。

正在暂停的任务仍不能提前继续；不同账号的凭据、进度及浏览器上下文保持隔离。同账号未结束任务仍去重，暂停不允许解绑。未完成的一题或材料可能重新进入，已经确认的积分保留。

平台拒绝、限流及验证错误仍失败，失败任务不能通过继续接口重试；验证码仍需本人处理，没有自动解码或绕过行为。

`app/test/task-pause.test.js` 覆盖手机/桌面移除按钮、原任务按钮恢复旧暂停任务、账号权限、关闭会话后继续、完成竞争与失联恢复。相关回归本地与服务器均通过。
