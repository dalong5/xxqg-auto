# 任务暂停与继续

主页“账号”卡片的按钮按“生成登录二维码 → 查当前积分 → 暂停任务 → 继续任务”排列；暂停按钮复用“生成登录二维码”的红色主按钮样式。暂停和继续始终可见，无账号或不适用当前任务状态时禁用，状态说明位于按钮下方。两者只作用于当前账号。排队任务立即暂停；执行中的任务先显示“正在暂停”，当前页面调用返回、停留循环或答题等待检测到请求后退出并关闭账号会话，才允许继续。其他账号使用自己的会话，不被关闭。

暂停释放执行名额，数据库保留任务和积分；刷新页面仍显示已暂停。继续时重新领取同一任务，先查官方进度，再跳过已经确认完成的项目。未完成的一题或材料可能需要重进，不承诺保留第三方页面临时输入。

运行与暂停的竞争由数据库状态转换处理；“正在暂停”不能提前继续。同账号不允许因暂停而创建第二个未结束任务或解绑账号。确认归属转移时旧暂停任务失效，避免新访客被旧任务阻塞。执行器失联时暂停请求也保持暂停，不自动重跑。

限流、拒绝、验证错误仍按失败处理；失败任务不可通过继续接口重试。人工验证等待可以被暂停退出，没有自动处理或绕过验证码。

验证代码：`app/test/task-pause.test.js` 覆盖真实页面按钮、API、SQLite 队列、执行器检查点及模拟浏览器关闭顺序；浏览器生命周期回归覆盖验证等待和长等待的中断。真实学习账号不用于回归测试。
