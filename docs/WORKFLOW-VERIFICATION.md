# 单账号流程修复与验证（2026-11-03）

## 本轮范围

沿用 Node 24、Express、SQLite 和 Playwright，先跑通已有单账号流程。

## 已修复

- 主账号 cookie 在数据库写入边界统一 AES-256-GCM 加密。
- 接通逐篇积分回查，回查失败立即停止。
- 阅读、视听和答题只有在官方积分达到动态上限后才报告完成，不再吞掉单项失败。

- 验证码展示实时画面并转发用户鼠标输入，超时明确失败。
- 人工输入检查访客、账号归属、任务状态、坐标和速率；重绑后旧访客失去权限。
- 转义昵称和错误消息，拒绝损坏的访客 cookie。
- 日期按 UTC+8 计算，自动读取本地 .env；修复数据库并发启动时锁等待设置顺序。
- Docker 改为 Node 24 和锁文件安装，构建排除数据与密钥。
